Contrato de endpoints para conectar cualquiera de los dos frontends con un backend real. Esta sección documenta el diseño; no ejecuta Laravel en GitHub Pages.

GET/api/tasksListar tareas
POST/api/tasksCrear tarea
PATCH/api/tasks/{id}Actualizar estado o título
DELETE/api/tasks/{id}Eliminar tarea

Ejemplo de controlador Laravel

<?php

namespace App\\Http\\Controllers\\Api;

use App\\Http\\Controllers\\Controller;
use App\\Models\\Task;
use Illuminate\\Http\\Request;

class TaskController extends Controller
{
    public function index()
    {
        return Task::query()->latest()->get();
    }

    public function store(Request $request)
    {
        $data = $request->validate([
            'title' => ['required', 'string', 'max:120'],
        ]);

        return response()->json(
            Task::create($data),
            201
        );
    }
}
Nota de despliegue: GitHub Pages publica contenido estático. Para convertir esta API en funcional, se debe desplegar Laravel en un servidor compatible con PHP y configurar la URL de la API, CORS, autenticación y persistencia de datos.
